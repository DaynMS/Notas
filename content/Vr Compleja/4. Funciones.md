## Exponencial $e^z$
$$\begin{align*}
    f(z) &=e^{x+yi} =e^x e^{yi} = e^x \cos y + i e^x \sin y\\
    &= e^{re^{i \theta}} = e^{r(\cos \theta + i \sin \theta)} = e^{r\cos \theta} e^{ir \sin \theta}
\end{align*}$$

### Propiedades
Si $z,w \in \mathbb{C}$
- $e^{z+w} = e^z e^w$
- $\dfrac{e^z}{e^w} = e^{z-w}$
- $\dfrac{d}{dz}e^z = e^z$ 
- $e^z = e^{z+2\pi i}$, es una función periódica de periodo $2\pi i$
- $e^z \ne 0$ para todo $z$

## Función logaritmo

En general las ecuaciones del tipo $$e^z =w $$ no tienen una única solución

<span class="defn">Definición:</span> Si $e^w = z$ con $z = re^{i(\theta + 2\pi k)}$, entonces 

$$\begin{align*}
    \log z &= \ln r + i(\theta + 2\pi k)\\
&= \ln |z| + i(Arg(z) + 2 \pi k)
\end{align*}$$

### Propiedades

- $e^{\log z} = z$
En dirección contraria: $\log e^z = z + 2\pi k i$, es multivaluada
- $\log (zw) = \log z + \log w$
- $\log \left(\dfrac{z}{w} \right) = \log z - \log w$
  - $arg(zw)= arg(z) + arg(w)$
- $z^n = e^{n \log z}$, con $n \in \Z$
- $z^{1/n} = \exp(\frac 1 n \log z)$ con $n \in \Z^+$
- $\dfrac{d}{dz}\log z = \dfrac{1}{z}$ 

Esta función es multivaluada, entonces en general no se cumplen las propiedades del logaritmo de los reales.
- $\log(z^a) \ne a\log z$

<span class="nota">Nota:</span> Si $z \in \R$, la definición de logaritmo debe coincidir con $\ln$ para los reales, así si $$\log z = \log x = \ln x$$ en este caso hay que obligar a que $z = x > 0$

### Logaritmo principal

<span class="defn">Definición:</span> El **logaritmo principal** se define como: $$\text{Log}\ z = \ln r + i \theta$$ donde $\theta$ es el argumento principal: $-\pi < \theta \le \pi$

en general no se tiene: $$\text{Log}(zw) \ne \text{Log}\ z + \text{Log}\ w$$

- $\log z = \text{Log} z + 2k\pi i$

## Función potencia
<span class="defn">Definición:</span>si $c \in \mathbb{C}$ $$z^c := e^{c \log z}$$

como la función definida así es multivaluada, se define el **valor principal** de $z^c$ como $$vp(z^c) = e^{c \text{Log} z}$$

### Función exponencial
Si la base es constante: $$f(z) = c^z$$

entonces $$f'(z) = c^z \log c$$

## Funciones trigonométricas

<span class="defn">Definición:</span> El **coseno** de un número complejo se define como $$\cos z = \frac{e^{iz} + e^{-iz}}{2}$$

<span class="defn">Definición:</span> El **seno** de un número complejo se define como $$\sin z = \frac{e^{iz} - e^{-iz}}{2i}$$

### Derivadas
derivando: $$\frac{d}{dz} \sin z = \cos z, \qquad \frac{d}{dz} \cos z = -\sin z$$

### Propiedades
- $\sin(z) = -\sin z$
- $\cos(-z) = \cos z$
- $\sin(z+w) = \sin z \cos w + \sin w \cos z$
- $\cos(z+w) = \cos z \cos w + \sin z \sin w$
- $\sin(z + \frac{\pi }{2}) = \cos z$
- $\sin^2 z + \cos^2 z = 1$

Como la función se definió usando la exponencial que no es multivaluada, la mayoría de las propiedades de los reales también se tienen.

### Hiperbólicas 
En los reales se definen las funciones:
$$\sinh y := \frac{e^y - e^{-y}}{2}, \qquad \cosh y := \frac{e^y + e^{-y}}{2}$$

se puede demostrar que $$\sin(iy) = i\sinh y, \qquad \cos(iy) = \cosh y$$

usando esto, se puede probar que $$\sin z = \sin x \cosh y + i \cos x \sinh y\\
\cos z = \cos x \cosh y - i \sin x \sinh y$$

<span class="defn">Definición:</span> Si $z \in \mathbb{C}$, $$\sinh z := \frac{e^z - e^{-z}}{2}, \qquad \cosh z := \frac{e^z + e^{-z}}{2}$$

### Cuándo dan $0$?
- $\sin z = 0$ si y sólo si $z = \pi k$
- $\cos z = 0$ si y sólo si $z = (2k+1)\frac{\pi}{2}$

## Funciones trigonométricas inversas
$$\sin^{-1} z = -i \log[ iz + (1-z^2)^{1/2}]$$

$$\cos^{-1} z = -i \log[ z + i(1-z^2)^{1/2}]$$
