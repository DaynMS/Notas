# Gram-Schmidt

La idea es construir una base ortonormal para todo espacio con producto interno.
Además, partiendo de una base se puede construir una lo más parecida que sea ortonormal (que no cambie el generado de los primeros $k$ elementos)

## Ortogonal y ortonormal 

<span class="defn">Definición:</span> Sea $V$ un espacio con producto interno, decimos que $x,y \in V$ son **ortogonales** o **perpendiculares** si $\langle x,y \rangle = 0$

<span class="defn">Definición:</span> Si $S \sube V$,  $S$ se dice
1. **ortogonal** si toda pareja de elementos de $S$ diferentes, es ortogonal.
2. **ortonormal** si es ortogonal y para todo $s \in S$ se tiene que $\|s\| = 1$

<span class="defn">Definición:</span>  Una **base ortonormal** de $V$ un espacio con producto interno, es una base que como conjunto es ortonormal.

<span class="teor">Teorema:</span> Sea $V$ un espacio con producto interno y sea $S = \{ v_1, \dots, v_k\}$ un subconjunto ortogonal de vectores diferentes no nulos. Si $y \in \langle S \rangle$ entonces $$ y = \sum_{i=1}^k \frac{ \langle y,v_i \rangle}{\| v_i\|^2} v_i \tag*{$\dblcolon$}$$

Como $y \in \langle S \rangle$, $y =a_1v_1 + \cdots + a_k v_k$, luego $a_i = \langle y,v_i \rangle / \| v_i\|^2$

<span class="teor">Corolario:</span> Si $S$ es ortonormal $ y = \sum_{i=1}^k \langle y,v_i \rangle v_i $

<span class="teor">Corolario:</span> Todo conjunto ortogonal de vectores no nulos, es linealmente independiente.
- Si se tiene una combinación lineal de los vectores, usando el teorema con los coeficientes $\langle 0, v_i \rangle =0$, así cada $a_i = 0$

## Gram-Schmidt

<span class="teor">Teorema:</span> **Procedimiento Gram-Schmidt**
Sea $V$ un espacio con producto interno y $S = \{ w_1, \dots, w_n \}$ un subconjunto de vectores linealmente independientes de $V$. Sea  $S' = \{ v_1, \dots, v_n\}$ donde $$\begin{align*}
    v_1 &= w_1\\
    v_k &= w_k - \sum_{j=1}^{k-1} \frac{ \langle w_k , v_j \rangle}{\| v_j\|^2} v_j, & \text{para } 2 \le k \le n
\end{align*}$$ Entonces $S'$ es un conjunto ortogonal tal que $$ \langle \{ v_1, \dots, v_k \}\rangle = \langle \{ w_1, \dots, w_k\}\rangle$$ para todo $k$. <span style="float: right;">$\dblcolon$</span>

<span class="teor">Corolario:</span> Todo espacio vectorial $V$ de dimensión finita con producto interno tiene una base ortonormal. Si $\beta = \{ v_1, \cdots, v_n\}$ es dicha base y $x \in V$ entonces $x = \sum_{i=1}^n \langle x,v_i \rangle v_i $

<span class="teor">Corolario:</span> Si $\beta = \{ v_1, \dots, v_n\}$ es una base ortonormal de $V$, un espacio vectorial con producto interno, y sea $T$ un operador lineal en $V$, con $A = [T]_\beta$. Entonces $A_{ij} = \langle T(v_j) , v_i \rangle$.

<span class="defn">Definición:</span> Sea $\beta$ un conjunto ortonormal en un espacio $V$ con producto interno. Definimos los **coeficientes de Fourier de $x \in V$ relativo a $\beta$** como los escalares $\langle x,y \rangle$ donde $y \in \beta$.

# Complementos ortogonales

<span class="defn">Definición:</span> Sea $V$ un espacio vectorial con producto intertno y $S \sube V$ no vacío, definimos $$
S^\perp := \{ v \in V : \langle  v,y\rangle = 0, \forall y \in S\}
$$ como el **complemento ortogonal** de $S$

No es necesario que $S$ sea subespacio. Pero $S^\perp$ resulta ser subespacio

<span class="teor">Teorema:</span> Sea $W$ un subespacio finito de un espacio vectorial con producto interno $V$, y sea $y \in V$. Entonces existen vectores únicos $u \in W$ y $z \in W^\perp$ tales que $y = u+z$.
De hecho, si $\{v_1, \dots, v_k\}$ es una base ortonormal de $W$ entonces $$u = \sum_{i=1}^k \langle y, v_i \rangle v_i \tag*{$\dblcolon$}$$

<span class="nota">Nota:</span> Como todo $y \in V$ se escribe de manera única: $V = W \oplus W^\perp$

<span class="teor">Corolario:</span> $u$ es el vector de $W$ que está más cerca a $y$.
Esto es: para todo $u'\in W$, $$\| y-u\| \le \| y-u'\|$$

<span class="defn">Definición:</span> $u = \sum_{i=1}^k \langle y, v_i \rangle v_i$ se llama la **proyección ortogonal** de $y$ sobre $W$

<span class="teor">Teorema:</span> Sea $S = \{ v_1, \dots, v_k\}$ un conjunto ortonormal en un espacio vectorial con producto interno $V$ de dimensión $n$, entonces:
1. $S$ se puede extender a una base ortonormal de $V$ $\{ v_1, \dots, v_k, v_{k+1}, \dots, v_n\}$ 
2. Si $W = \lang S \rangle$, entonces $S_1 = \{v_{k+1}, \dots, v_n\}$ es una base ortonormal de $W^\perp$
3. Si $W$ es subespacio de $V$ entonces $\dim(V) = \dim(W) + \dim(W^\perp)$<span style="float: right;">$\dblcolon$</span>
