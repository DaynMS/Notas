# Medida cero

>[!definicion] Definición
>Decimos que $A \sube \R^n$ tiene **medida cero** ($n-$dimensional) si para cada $\epsilon>0$ existe una cobertura **enumerable** $\{U_1, U_2, \dots\}$ de $A$ por rectángulos cerrados (o abiertos) tal que $\sum_{i=1}^\infty V(U_i) < \epsilon$.

En particular si $B \sube A$ y $A$ tiene medida cero, entonces $B$ tiene medida cero.

>[!ejemplo]- 
>- Todo conjunto finito tiene medida cero.
>- Todo conjunto enumerable tiene medida cero.
>   - $\mathbb Q \cap [0,1]$ tiene medida cero.

>[!teorema] 
>Si $A = \bigcup_{i=1}^\infty A_i$ y cada $A_i$ tiene medida cero, entonces $A$ tiene medida cero.

# Contenido cero 

>[!definicion] Definición
>Decimos que $A \sube \R^n$ tiene **contenido cero** ($n-$dimensional) si para cada $\epsilon>0$ existe una cobertura **finita** $\{U_1, \dots, U_m\}$ de $A$ por rectángulos cerrados (o abiertos) tal que $\sum_{i=1}^\infty V(U_i) < \epsilon$.

Observe que si $A$ tiene contenido cero entonces también tiene medida cero.

>[!teorema] 
>Si $a<b$, entonces $[a,b] \sub \R$ no tiene contenido cero.

Si  $\{U_1, \dots, U_m\}$ es un cubrimiento de $[b-a]$, entonces
$$
\sum_{i=1}^m V(U_i) \ge b-a
$$

>[!teorema] 
>Si $A \sub \R^n$ es compacto y tiene medida cero, entonces tiene contenido cero.

>[!ejemplo]- 
>$\mathbb Q \cap [0,1]$ tiene medida cero, pero no tiene contenido cero, para cualquier cubrimiento $\sum_{i=1}^m V(U_i) \ge 1-0 $


# Funciones integrables

Sea $f: A \sub \R^n \to \R$ una función acotada. Dado $a \in A$ y $\delta >0$ se definen:
$$
M(f,a,\delta) = \sup \{f(x) : x \in A, \|x-a\| < \delta\}\\
m(f,a,\delta) = \inf \{f(x) : x \in A, \|x-a\| < \delta\}
$$

>[!definicion] Definición
>La **oscilación** de $f$ en $a$ se define como 
>$$
> \mathcal O (f,a) = \lim_{\delta \to 0} [M(f,a,\delta) - m(f,a,\delta)]
>$$

siempre existe porque para cualquier $\delta$:
$$
M(f,a,\delta) - m(f,a,\delta) \ge 0
$$

- $f$ es continua en $a$ si y sólo si $\mathcal O (f,a) = 0$.
- Si $f: A \to \R$ es acotada, $A \sub \R^n$ es cerrado y dado $\epsilon>0$, entonces $\{x \in A: \mathcal O (f,x) \ge \epsilon\}$ es cerrado.

>[!lema] 
>Sean $\epsilon>0$, $A \sub \R^n$ un rectángulo cerrado y $f: A \to \R$ una función acotada tal que $ \mathcal O (f,x) < \epsilon$ para todo $x \in A$. Entonces existe una partición $P$ de $A$ tal que
>$$
> U(f,P) - L(f,P) < \epsilon \cdot V(A)
>$$

>[!teorema] 
>Sean $A \sub \R^n$ un rectángulo cerrado y $f: A \to \R$ una función acotada. Sea $B = \{ x \in A : f \text{ es discontinua en } x\}$. Entonces $f$ es integrable en $A$ si y sólo si $B$ es un conjunto de medida cero

## Integrales sobre conjuntos no rectangulares

>[!definicion] Definición
>Sea $\mathsf C \sub \R^n$ un conjunto. Se define la **función caraterística** de $\mathsf C$ como:
>$$
>\begin{align*}
>    \chi_{\mathsf C} : \R^n &\to \R\\
>    x &\mapsto \begin{cases}
>        0; & x \notin \mathsf C\\
>        1; & x \in \mathsf C\\
>    \end{cases}
>\end{align*}
>$$

>[!definicion] Definición
>Si $\mathsf C \sub A$, para algún rectángulo cerrado $A$ de $\R^n$ y $f: A \to \R$ es acotada, entonces la **integral** de $f$ sobre $\mathsf C $ se define como
>$$
>\int_{\mathsf C } f = \int_A f \chi_{\mathsf C} 
>$$

Siempre que la función 
$$
\begin{align*}
    f \chi_{\mathsf C} : A \sub \R^n &\to \R\\
    x &\mapsto f(x) \cdot \chi_{\mathsf C}(x)
\end{align*}
$$
sea integrable, lo que ocurre si $f$ y $\chi_{\mathsf C}$ son integrables

>[!teorema] 
>$\chi_{\mathsf C}|_A: A \to \R$ es integrable si y sólo si la frontera de $\mathsf C$ tiene medida cero.  
>>[!demostracion]- Demostración
>Se cumple que $\partial \mathsf C$ corresponde al conjunto de discontinuidades de $\mathsf C$, por el teorema anterior se tiene el si y sólo si.

Además $\partial \mathsf C$ tiene contenido cero porque es compacto (subconjunto de un compacto en $\R^n$).


## Jordan-medible
>[!definicion] Definición
>Un conjunto acotado $\mathsf C$ tal que su frontera tiene medida cero se dice **Jordan-medible**
>- $\int_{\mathsf C} 1$ se llama el **contenido** o **volumen** $n-$**dimensional** de $\mathsf C$

>[!nota] 
>Existen conjuntos $\mathsf C$ que no son Jordan-medibles. Así que $\int_{\mathsf C} f$ puede no existir aún si $\mathsf C$ es abierto y $f$ es continua.
